# CEE-Kopie von SolidCraft

Diese Kopie von `tangency-labs/solidcraft` gleicht sich wöchentlich mit dem Original ab
(`.github/workflows/cee-abgleich.yml`, ADR-068 im Projekt `lobito42/cee`). Eigene CEE-Teile liegen nur in
`cee/` und in Crates `crates/cee-*`, damit der Abgleich nie mit ihnen kollidiert. Die Abläufe des Originals
sind hier bewusst entfernt (eigene Läufer, Veröffentlichung); geprüft wird beim Abgleich.
